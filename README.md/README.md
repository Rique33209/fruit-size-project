# Fruit Size Analysis Project

## Overview

Ths project analysis fruit size data using Python and displays the result in an Visual Studio code dashboard.

## Dataset

File: fruit_size_data.xlsx

Columns:
-id
-header_id
-size_in_mm_actual
-size_in_mm_estimate
-dffb_less_than_min
-size_count
-estimated_mass
-processed_dts

## Initial Observations

-Dataset contains fruit size measurements.
-Actual fruit sizes range from approximately 12mm to 38mm.
-Estimated size range from approximately 49mm to 77mm.
-Estimated mass ranges from approximately 63g to 185g.
-The dffb_less_than_min column contains binary values (0 and 1).
-Records are grouped by header_id. 

## Objectives

1. Read the excel files usinf Python.
2. Clean and analyse the data.
3. Generate useful statistics.
4. Create charts and visualisations.
5. Display results in an Visual Studio code dashboard.

## Technologies Used
-Python
-Git
-Pandas
-Github
-Visual Studio Code
-HTML

## Findings

-Analyzed fruit size data using Python.
-Calculated average fruit sizes.
-Compared fruit groups using header_id.
-Calculated estimated mass statistics.
-Created a bar chart showing average fruit size by group.

## Conclusion

This project analysed fruit size data using Python.

The dataset was explored, cleaned, and summarised using Pandas. Statistical analysis was performed on fruit sizes and estimated masses. A bar chart was generated to visualise average fruit size by header_id. Results were presented through an HTML dashboard.
